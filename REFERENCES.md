# References

These projects are why this repo is a set of agent-readable skills plus tokens. They are credits, not dependencies. Do not vendor them, and do not copy their text, rules, or assets into this repo. Read them at the source.

- Impeccable, by Paul Bakaus. A design vocabulary for coding agents. <https://github.com/pbakaus/impeccable>
- Hallmark, by Nutlope. An anti-slop design skill for coding agents. <https://github.com/Nutlope/hallmark>
- UI UX Pro Max, by nextlevelbuilder. Design guidance for coding agents. <https://github.com/nextlevelbuilder/ui-ux-pro-max-skill>

"Hallmark" in the brief for this kit refers to the Nutlope repository above.
